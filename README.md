# 在线花店系统

## 前端功能介绍

### 1. 首页
 - 轮播图：展示重要的商品或活动信息，吸引用户注意力。
 - 分类导购：方便用户快速定位到感兴趣的商品类别。
 - AI 花艺助手入口：为用户提供进入 AI 花艺助手功能的通道。

### 2. 管理员编辑页
具备编辑商品基本信息（如名称、价格、描述、库存等）和分类信息（如分类名称、分类层级等）的功能，便于管理员对商品数据进行管理和更新。

### 3. 商品选购页
与后端进行数据交互，获取当前类别商品的相关数据，并以分类的形式展示商品，展示内容包含但不限于：
 - 商品图片：直观呈现商品外观。
 - 商品名称：清晰显示商品名称。
 - 商品价格：明确标注商品价格。
 - 商品简介：简要介绍商品特点和功能等。

### 4. 购物车页
由以下组件构成：
 - 收货信息选择组件：用户可选择或添加收货地址信息。
 - 时间选择组件：用户能够选择期望的商品送达时间。
 - 选择商品组件：用户可以对已添加到购物车的商品进行数量修改、删除等操作。

### 5. 订单查看页
 - 历史订单查看：用户可浏览自己的历史订单记录。
 - 筛选及排序：支持按照不同条件（如订单时间、订单状态等）对订单进行筛选和排序。
 - 详情查看：用户点击具体订单可查看详细的订单信息，如商品详情、支付信息、物流信息等。

### 6. 个人资料页
包含以下组件：
 - 修改基本信息组件：用户可修改个人基本信息，如姓名、联系方式等。
 - 收货信息管理组件：对收货地址进行添加、编辑、删除等操作。
 - 修改密码组件：用户可修改登录密码，保障账户安全。
 - 登出组件：用户点击可退出当前登录状态。

### 7. AI 花艺助手页
根据用户的个性化需求，为用户提供专业的花艺相关建议，如花卉搭配、花艺设计方案等。
