# 花卉商城系统
## 项目概述
本项目是一个在线花店系统，采用前后端分离架构。前端基于React构建交互界面，搭配Ant Design组件库，实现简洁美观的用户体验；后端基于Spring Boot开发RESTful API，结合MyBatis、Redis等技术，保障系统高效稳定运行。系统涵盖用户管理、鲜花展示、订单处理、AI花艺咨询等核心功能，满足花卉电商的全流程业务需求。

## 项目结构

## 前端部分
### 技术栈
- **React**：高效构建交互式UI组件。
- **Ant Design**：提供丰富的React组件，加速界面开发。
- **Axios**：实现前后端数据交互的HTTP客户端。
- **Redux Toolkit**：简化状态管理，提升数据处理效率。

### 运行步骤
1. 进入前端目录：`cd frontend`
2. 安装依赖：`npm install`
3. 启动开发服务器：`npm start`
4. 访问：[http://localhost:3000](http://localhost:3000)

### 其他命令
- 单元测试：`npm test`
- 生产构建：`npm run build`

## 后端部分
### 技术栈
- **Spring Boot**：快速搭建企业级后端服务。
- **MyBatis**：实现数据库操作的高效映射。
- **Spring Data Redis**：缓存数据，提升系统响应速度。
- **Spring Retry**：增强系统容错能力，自动重试失败操作。
- **JJWT**：基于JWT实现安全的用户认证。

### 运行步骤
1. 进入后端目录：`cd backend`
2. 编译打包：`mvn clean package`
3. 启动服务：`java -jar target/backend-0.0.1-SNAPSHOT.jar`

### 配置说明
通过`backend/src/main/resources/application.properties`配置数据库连接、Redis参数及DeepSeek API密钥等关键信息。

## 注意事项
1. 确保开发环境已安装Node.js（建议v14+）和Java（建议JDK 11+）。
2. 根据实际环境修改后端配置文件中的数据库及API密钥等敏感信息。

## 前端功能详解
### 1. 首页
- **轮播图**：动态展示热门商品或促销活动。
- **分类导航**：支持快速跳转至花卉分类页面。
- **AI 花艺助手入口**：一键访问智能花艺咨询服务。

### 2. 管理员编辑页
支持商品信息（名称、价格、库存等）及分类信息（层级、标签）的增删改查操作。

### 3. 商品选购页
实时同步后端数据，以分类形式展示商品详情，包含：
- 商品图片
- 名称与价格
- 核心卖点简介

### 4. 购物车页
集成多交互组件：
- **收货地址管理**：支持添加/修改收货信息
- **配送时间选择**：自定义商品送达时间
- **商品操作**：调整数量、删除商品

### 5. 订单查看页
提供全流程订单管理：
- 历史订单浏览
- 多条件筛选排序（时间、状态等）
- 订单详情查询（商品清单、物流信息）

### 6. 个人资料页
涵盖用户信息管理模块：
- 基础信息修改（姓名、联系方式）
- 收货地址维护
- 密码安全修改
- 安全登出功能

### 7. AI 花艺助手页
基于用户需求（场景、预算、风格），提供个性化花艺搭配方案及设计建议。

## 后端功能详解

### 1. 用户管理
- **登录与注册**：用户可以使用手机号和密码进行注册和登录操作。登录成功后，系统会生成并返回 JWT Token，用于后续的身份验证和授权。
- **用户信息管理**：用户可以查看个人信息，修改基本信息（如用户名、手机号）和密码。修改手机号时，系统会验证新手机号是否已被使用。
- **权限管理**：通过 JWT Token 中的信息判断用户是否为管理员，管理员拥有更高的操作权限，如修改订单状态、管理鲜花信息等。

### 2. 订单管理
- **提交订单**：用户登录后可以提交订单，系统会记录订单信息和商品项信息，生成唯一的订单编号，并计算订单总金额。
- **更新订单状态**：管理员可以更新订单状态，如已支付、已发货、已完成等。系统会记录订单状态变更日志，并根据不同状态更新相应的时间字段。
- **订单查询**：用户可以根据订单状态、排序字段等条件查询自己的订单列表和订单详情。管理员可以根据更多条件（如搜索关键词、时间范围等）查询所有订单，并支持分页功能。

### 3. 鲜花管理
- **添加鲜花**：管理员可以添加新的鲜花信息，包括基本信息（名称、描述、价格、图片等）和分类信息（主花、用途、色系、支数等）。系统会将信息分别存储到鲜花表和分类表中，并确保事务一致性。
- **删除鲜花**：管理员可以根据鲜花 ID 删除对应的鲜花信息，同时删除相关的分类信息。
- **修改鲜花信息**：管理员可以修改鲜花的基本信息和分类信息，系统会验证信息的有效性并更新数据库。
- **查询鲜花信息**：用户可以查询所有鲜花信息，也可以根据分类类型和值（如用途、主花等）查询符合条件的鲜花列表。

### 4. 收货地址管理
- **添加收货地址**：用户可以添加新的收货地址，系统会关联用户 ID 并保存地址信息。
- **删除收货地址**：用户可以删除自己的收货地址，系统会验证地址的所有权并进行删除操作。
- **修改收货地址**：用户可以修改已有的收货地址信息。
- **查询收货地址**：用户可以查询自己的所有收货地址，也可以设置默认收货地址。

### 5. AI 咨询服务
- **提供花束建议**：用户可以向 AI 花艺师助手咨询花束建议，系统会调用 DeepSeek 模型生成响应。为了提高性能，系统采用了缓存和重试机制。
- **花卉知识查询**：系统内置了花卉知识库，包含花材的含义、不同场景和收花人的建议等信息，可以为用户提供相关的花卉知识。
